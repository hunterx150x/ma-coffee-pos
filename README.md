# MA Coffee POS

ระบบขายหน้าร้านกาแฟ (Responsive Web App สำหรับมือถือ / iPad / แท็บเล็ต)

## เริ่มใช้งาน

ต้องมี Node.js 16 ขึ้นไป

```bash
npm install
npm run build     # สร้างหน้าเว็บ
npm start         # เปิดระบบที่ http://localhost:3001
```

เปิดจาก iPad / มือถือ ที่อยู่ Wi-Fi เดียวกัน: `http://<IP เครื่องที่รัน>:3001`
(กด “เพิ่มไปยังหน้าจอโฮม” ใน Safari เพื่อใช้แบบเต็มจอเหมือนแอป)

โหมดพัฒนา (แก้โค้ดแล้วหน้าเว็บรีเฟรชเอง): `npm run dev` แล้วเปิด http://localhost:5173

### บัญชีเริ่มต้น (เปลี่ยนรหัสผ่านหลังเข้าใช้ครั้งแรก)

| ชื่อผู้ใช้ | รหัสผ่าน | สิทธิ์ |
|---|---|---|
| admin | admin1234 | เจ้าของร้าน (ทุกเมนู) |
| staff | 1234 | พนักงาน (ขายหน้าร้าน, ประวัติการขาย) |

## ข้อมูล

ข้อมูลทั้งหมดเก็บที่ `data/db.json` (สร้างอัตโนมัติพร้อมเมนูตัวอย่างเมื่อรันครั้งแรก)
สำรอง/กู้คืนได้ที่เมนู “ตั้งค่าร้าน” — ตั้งค่า `DATA_DIR`, `PORT`, `TZ` ผ่าน environment variable ได้

## Deploy ขึ้นเว็บแบบฟรี (Render + Neon)

โฮสต์ฟรีจะลบไฟล์ทุกครั้งที่รีสตาร์ท จึงต้องเก็บข้อมูลใน Postgres ฟรีของ Neon (ตั้ง `DATABASE_URL` แล้วระบบจะใช้ Postgres อัตโนมัติ)

1. **Neon** — สมัครที่ https://neon.tech → Create project (Region: Singapore) → คัดลอก *Connection string* (`postgresql://...`)
2. **GitHub** — สร้าง repository ใหม่ (Private ก็ได้) แล้ว push โค้ดนี้ขึ้นไป
3. **Render** — สมัครที่ https://render.com ด้วยบัญชี GitHub → **New → Blueprint** → เลือก repository นี้ (ใช้ `render.yaml`) แล้วกรอก
   - `DATABASE_URL` = connection string จาก Neon
   - `ADMIN_PASSWORD` = รหัสผ่านเจ้าของร้าน (ตั้งให้เดายาก)
   - `STAFF_PASSWORD` = รหัสผ่านพนักงานเริ่มต้น
4. รอ build เสร็จ จะได้ลิงก์ `https://ma-coffee-pos.onrender.com` (หรือชื่อใกล้เคียง)

> รหัสผ่านจาก env ใช้ตอนสร้างฐานข้อมูลครั้งแรกเท่านั้น หลังจากนั้นเปลี่ยนรหัสผ่านในแอป

**ข้อจำกัดของแพ็กเกจฟรี:** Render จะหลับเมื่อไม่มีคนใช้ 15 นาที และเปิดครั้งแรกหลังหลับจะช้า ~1 นาที
แก้ได้โดยตั้ง https://uptimerobot.com (ฟรี) ให้เรียก `https://<ลิงก์ของคุณ>/api/health` ทุก 5 นาที

## แจ้งเตือน LINE (ไม่บังคับ)

ตั้ง env บนเซิร์ฟเวอร์ (ใน Render → Environment หรือไฟล์ `.env` ตอนรันในเครื่อง — ห้าม commit):

| ตัวแปร | ได้จาก |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | LINE Developers → Channel → Messaging API → Channel access token (long-lived) |
| `LINE_CHANNEL_SECRET` | LINE Developers → Channel → Basic settings → Channel secret |
| `LINE_GROUP_ID` | Group ID ของกลุ่มร้าน (หรือเลือกในหน้า “ตั้งค่าร้าน” หลังตั้ง webhook) |

Webhook URL: `https://<โดเมน>/api/line/webhook` — คำสั่งในกลุ่ม: `ยอดวันนี้`, `สต๊อก`

## ฟีเจอร์

- **ขายหน้าร้าน 8 ขั้นตอน**: ลูกค้าใหม่/เก่า → ประเภท → เมนู → ความหวาน → ท็อปปิ้ง → ส่วนลด → สรุปรายการ (เพิ่มเมนู / ยืนยัน) → ชำระเงิน (เงินสดพร้อมคำนวณเงินทอน / เงินโอนพร้อม QR พร้อมเพย์)
- **ส่วนลด** 3 แบบ: ลดเป็นบาท, ลดเป็น %, ฟรี 1 แก้ว (กำหนดราคาสูงสุด เช่น ≤ 40 บาท)
- **รายงาน**: เลือกวันนี้ / เมื่อวาน / สัปดาห์นี้ / เดือนนี้ / เดือนที่แล้ว หรือกำหนดช่วงวันที่เอง — ยอดเงินสด, เงินโอน, ยอดรวม, งบกำไร-ขาดทุน, สรุปรายวัน, เมนูขายดี, ส่งออก CSV
- **ต้นทุน**: กรอกเองต่อเมนู หรือคำนวณจากสูตรวัตถุดิบ (ใช้คิดกำไรในรายงาน)
- **สต๊อก**: ตัดวัตถุดิบอัตโนมัติตามสูตรเมื่อขาย, รับเข้า (คำนวณต้นทุนเฉลี่ยใหม่), เบิกออก, ตรวจนับ, แจ้งเตือนใกล้หมด, ประวัติเคลื่อนไหว
- **ผู้ใช้ & สิทธิ์**: เจ้าของร้าน/พนักงาน, เลือกเมนูที่พนักงานแต่ละคนเข้าได้, ระงับบัญชี
- **อื่นๆ**: ค่าใช้จ่าย (หักในกำไรสุทธิ), ข้อมูลลูกค้า, ยกเลิกบิล (คืนสต๊อก), พิมพ์ใบเสร็จ
- **ลูกค้าสั่งเอง (QR)**: ลิงก์สาธารณะ `/order` (สร้าง/พิมพ์ QR ได้ที่ “ตั้งค่าร้าน”) — ลูกค้ากรอกชื่อ → เลือกเมนู → ยืนยัน แล้วเข้าคิวทันที ดูลำดับคิวของตัวเองแบบ realtime ที่ `/order/q/<token>`
- **รูปเมนู**: อัปโหลดได้ในฟอร์มเมนู (ย่อขนาดในเบราว์เซอร์ เก็บแบบ base64) ไม่มีรูปจะแสดงไอคอนของประเภท
- **สะสมแต้มสมาชิก**: 1 แก้ว = 1 แต้ม (ได้เมื่อชำระเงิน) ครบ 9 แต้มแลกฟรี 1 แก้ว (≤ 40 ฿) สะสมแลกหลายแก้วได้ · ใช้เบอร์โทรเป็นรหัสสมาชิก · แลกได้ที่หน้าขาย (ขั้นตอนส่วนลด) และตอนชำระคิว · ยกเลิกบิลแล้วแต้มคืนอัตโนมัติ · ตั้งค่ากติกาได้ที่ “ตั้งค่าร้าน”
